# Currency Converter

## Автор: Алтынай Зайдуллина

## Описание
Графическое приложение для конвертации валют. Использует актуальные курсы с сайта exchangerate-api.com. История операций сохраняется в файл `history.json`.

## Требования
*   Python 3.7+
*   Библиотеки: `requests`, `tkinter` (входит в стандартную библиотеку Python).

## Установка и запуск

1.  **Установите зависимости:**
    ```bash
    pip install requests
    ```
2.  **Получите API-ключ:**
    Зарегистрируйтесь на сайте [exchangerate-api.com](https://www.exchangerate-api.com/) и вставьте полученный ключ в переменную `API_KEY` в начале файла `main.py`.
3.  **Запустите приложение:**
    ```bash
    python itogwork.py
    ```
4.  **Использование:**
    *   Выберите валюту "Из" и "В".
    *   Введите сумму.
    *   Нажмите "Конвертировать".
    *   Результат появится справа.
    *   Все операции сохраняются в таблицу ниже.
